# 卡通小卡片生成方法

这份说明给上传照片的人使用。当前网页流程不会自动生成卡通小卡片，用户需要先自己把每张原照片生成一张对应的小卡片，然后在 GitHub Issue 表单里同时上传原照片和小卡片。

核心规则：

- 一张原照片必须对应一张小卡片。
- 原照片和小卡片的上传数量必须一致。
- 上传顺序必须一致：第 1 张小卡片对应第 1 张原照片，第 2 张对应第 2 张，以此类推。
- 小卡片建议保存为 PNG，也可以使用 JPG。
- 生成小卡片时要用“图片编辑 / 图片到图片”模式，不要只用文字从零生成。

## 推荐生成方式

先准备好要上传的原照片。对每张照片，从下面两种风格里任选一种生成小卡片。

## 风格一：蜡笔彩铅回忆卡

适合温暖、日常、居家、做饭、自拍、滑雪、旅行途中比较柔和的照片。

推荐提示词：

```text
请把这张真实照片改成温暖的手绘蜡笔和彩铅回忆小卡片。

保留原照片的构图、人物、姿势、脸部朝向、衣服、重要物品、背景和画面比例。
风格是纸张纹理明显、蜡笔笔触、彩铅阴影、线条略微不均匀、颜色温柔、人物五官简化但仍然能认出来。
整体感觉像私人相册里的温暖回忆卡，不要像幼稚卡通。

不要添加文字、水印、边框、UI、贴纸、额外人物或无关物品。
不要变成动漫风、吉祥物风、扁平矢量风、油画风或厚黑线漫画风。
```

如果是滑雪或雪景照片，可以追加：

```text
请保留雪地、天空、头盔、雪镜、外套、原来的自拍构图和明亮冬天氛围。
```

如果是在家、做饭或吃饭照片，可以追加：

```text
请保留厨房、餐桌、锅具、食物、电脑或桌面物品，以及原来的日常生活氛围。
```

## 风格二：旅行涂鸦明信片

适合旅行、出门玩、街景、机场、酒店、雪场、水边、聚会、比较有趣的照片。

推荐提示词：

```text
请把这张真实照片改成幽默可爱的手绘旅行日记涂鸦明信片。

保留原照片的构图、画面比例、主要人物、姿势、拍摄角度、地点和重要背景物品。
把照片转成粗糙墨线、彩铅上色、柔和粉彩、可见纸张纹理、略微不均匀的手绘线条和轻松的手账感。

可以少量加入中文手写批注、气泡、箭头、搞笑小旁白和一两个拟人化小物件，但不要挡住人物脸部。
人物要能认出来，整体要可爱但不要幼稚。

不要水印、不要 UI、不要厚重装饰边框、不要添加无关的新物品。
```

可选短批注示例：

- 滑雪：`雪地勇士`、`coach 上线`、`摔倒也可爱`
- 出游：`今日路线：快乐`、`出门小坐标`、`走走停停`
- 做饭：`美厨娘时刻`、`今日好吃`、`开饭啦`
- 水边：`泡泡熊出没`、`水里也要自拍`、`快乐值+1`

## 生成后检查

每张小卡片上传前都检查一次：

- 人物是否还能认出来。
- 场景和构图是否基本保持原样。
- 有没有多出来的无关人物或物品。
- 有没有水印、工具界面、明显错误文字。
- 小卡片有没有挡住脸部或关键画面。
- 原照片和小卡片数量是否一致。
- 文件顺序是否已经排好。

如果不满意，优先只针对问题重试一次。例如：

- 太像照片：增加“更明显的蜡笔纹理、纸张颗粒、彩铅阴影”。
- 人物不像：增加“保留人物身份、位置、衣服、发型和脸部朝向”。
- 场景变了：明确写出必须保留的地点、物品和背景。
- 文字太乱：要求“不要文字，只保留少量箭头和涂鸦装饰”。

## 上传前整理

建议把文件临时整理成两组：

```text
原照片：
01.jpg
02.jpg
03.jpg

卡通小卡片：
01-card.png
02-card.png
03-card.png
```

上传到 GitHub Issue 时，先上传所有原照片，再上传所有小卡片。两组内部顺序必须对应。
